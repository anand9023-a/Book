પ્રશ્ન 2
M દળનો એક કણ સમક્ષિતિજ અક્ષ પર x = 0 થી x = L સુધી ગતિ કરે છે. ગતિક ઘર્ષણાંક x ના વિધેય તરીકે નીચે મુજબ બદલાય છે: μk(x) = μ0 - αx, જ્યાં μ0 અને α યોગ્ય પરિમાણો ધરાવતા અચળાંકો છે, જેથી μk(L) = 0 થાય. આ ગતિ દરમિયાન ઘર્ષણ બળ દ્વારા થતું કુલ કાર્ય n μ0MgL છે, જ્યાં g ગુરુત્વપ્રવેગ છે. n નું મૂલ્ય કેટલું હશે? (RE-NEET 2026)
વિકલ્પો:
A. 1/2
B. 3
C. 1
D. 1/3
જવાબ: A
ઉકેલ:
આપેલ છે: μk(x) = μ0 - αx અને μk(L) = 0 = μ0 - αL ⇒ μ0 = αL
ઘર્ષણ બળ દ્વારા થતા કાર્યનું મૂલ્ય, Wf = ∫ dWf જ્યાં Wf = fk dx = μk N dx = μk Mg dx = (μ0 - αx) Mg dx
Wf = ∫0L μ0 Mg dx - ∫0L α Mg x dx = μ0 Mg [x]0L - α Mg [x²/2]0L
⇒ n μ0 MgL = μ0 MgL - (μ0/L) Mg (L²/2) = (μ0 MgL) / 2
તેથી, n = 1/2
પ્રશ્ન 3
ભારે દળ m ધરાવતા એક લોલકને l લંબાઈની હલકી દોરી વડે લટકાવવામાં આવેલ છે. લોલકને આકૃતિમાં દર્શાવ્યા મુજબ સમક્ષિતિજ વેગ v0 આપવામાં આવે છે. જો દોરી સમક્ષિતિજ સાથે θ ખૂણો બનાવતા કોઈ બિંદુ P પર ઢીલી પડે, તો બિંદુ P પાસે લોલકની ઝડપ v અને તેની પ્રારંભિક ઝડપ v0 નો ગુણોત્તર છે: (NEET 2025)
વિકલ્પો:
A. (cos θ / (2 + 3 sin θ))1/2
B. (sin θ / (2 + 3 sin θ))1/2
C. (sin θ)1/2
D. (1 / (2 + 3 sin θ))1/2
જવાબ: B
ઉકેલ:
બિંદુ P પર, mg sin θ = mv² / l --- (1)
બિંદુ P અને Q વચ્ચે યાંત્રિક ઉર્જાના સંરક્ષણ મુજબ:
½ mv0² = ½ mv² + mg(l + l sin θ)
v0² / 2 = v² / 2 + gl(1 + sin θ)
સમીકરણ (1) પરથી gl = v² / sin θ મુકતા,
v0² / 2 = v² / 2 + (v² / sin θ)(1 + sin θ)
v0² = v² [3 + 2 / sin θ]
v / v0 = (sin θ / (3 sin θ + 2))1/2
પ્રશ્ન 4
બે સમાન કાર A અને B ની ગતિ ઊર્જા અનુક્રમે 100 J અને 225 J છે. બ્રેક લગાવ્યા પછી, કાર A 1000 m અંતર કાપીને અને કાર B 1500 m અંતર કાપીને ઊભી રહે છે. જો FA અને FB એ અનુક્રમે કાર A અને B પર બ્રેક દ્વારા લગાડવામાં આવતા બળો હોય, તો FA / FB નો ગુણોત્તર કેટલો થશે?
વિકલ્પો:
A. 1/3
B. 1/2
C. 3/2
D. 2/3
જવાબ: D
ઉકેલ:
કાર્ય-ઊર્જા પ્રમેય મુજબ: FS = ΔKE
અંતિમ ગતિ ઊર્જા શૂન્ય છે, તેથી: FS = ki
FA · SA = kA અને FB · SB = kB
FA / FB = (kA / kB) × (SB / SA) = (100 / 225) × (1500 / 1000) = 2/3

સ્થિર રહેલો 5m દળનો એક કણ અચાનક પોતાની મેળે ત્રણ ટુકડાઓમાં વિસ્ફોટ પામે છે. m દળના બે ટુકડાઓ એકબીજાને લંબ દિશામાં દરેકમાં v ઝડપથી ગતિ કરે છે. આ પ્રક્રિયા દરમિયાન મુક્ત થતી ઊર્જા કેટલી છે?
વિકલ્પો:
A. 3/5 mv²
B. 5/3 mv²
C. 3/2 mv²
D. 4/3 mv²
જવાબ: D
ઉકેલ:
વેગમાનના સંરક્ષણ મુજબ:
3m v→ + mvî + mvĵ = 0
⇒ |v→| = (√2 / 3) v
મુક્ત થતી ઊર્જા:
= ½ mv² + ½ mv² + ½ (3m) [ (√2/3)v ]² = mv² + 1/3 mv² = 4/3 mv²
